接入提醒

管理端默认仅监听回环地址。通过 SSH 隧道访问，或在设备上显式设置 LAN 监听并限制防火墙。DNS 前置服务默认 127.0.0.1:5353，dae DNS 为 127.0.0.1:5354；将 dnsmasq 上游配置为前置服务后，验证内网域名与外网分流。

管理器不自动更改现有 DHCP、防火墙或停用其他代理。请按安装包 README 完成网络接入和实机验收。
